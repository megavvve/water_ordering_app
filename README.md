## **Водовоз - Приложение для доставки воды**

### Описание

"Водовоз" — это приложение для доставки воды, разработанное на Flutter. Приложение позволяет пользователям размещать заказы на доставку воды, отслеживать их и получать уведомления. Также интегрировано с Firebase для хранения данных, обмена сообщениями и уведомлений, а также использует геолокацию для улучшенной функциональности.

---

### **Функции**

* **Функции для пользователей**:

  * Геолокация для отслеживания местоположения
  * Управление заказами (размещение, обновление, отмена)
  * Интеграция с Firebase для синхронизации данных в реальном времени
  * Уведомления о статусе доставки через Firebase Messaging
  * Отслеживание доставки на карте с использованием `yandex_mapkit`
* **Админ панель**:

  * Управление заказами пользователей и статусами доставки
  * Мониторинг активности пользователей и маршрутов доставки
  * Фильтрация заказов по городам
  * Обновления в реальном времени и уведомления

---

### **Технологический стек**

* **Frontend**:

  * Flutter SDK
  * Flutter Bloc для управления состоянием
  * Firebase для хранения данных, сообщений и аналитики
  * Yandex Maps для отслеживания и работы с геолокацией
* **Backend**:

  * Appwrite
